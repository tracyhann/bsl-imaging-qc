# BSL QC Workflow Hub

This directory is a self-contained static bundle for the QC workflow pages.

## Contents

- `index.html`: central hub with MRI and EEG tabs.
- `mri/`: copied MRI QC workflow page, source Markdown, and local assets.
- `eeg/`: copied EEG QC workflow page, source Markdown, and local assets.

## Deploy

Deploy this directory as the root of a static site, such as GitHub Pages. No build step is required.
